# Approved Reference Images

이 디렉터리는 사용자가 승인한 Tetris 시각 참고 원본을 보관한다.

- 여기에 있는 파일은 Godot runtime 소비처가 없는 `APPROVED_REFERENCE`다.
- `TETRIS-IMAGE-030`에 따라 runtime asset, runtime-integrated asset, 또는 runtime 검증 증거로 해석하지 않는다.
- 각 승인 원본은 이 프로젝트 경로와 `APPROVED_REFERENCE_MANIFEST.json`에 같은 SHA-256으로 보관한다.
- 새 승인 이미지는 원본 파일, 해시, 승인 범위, repository manifest 레코드를 함께 추가한다.

현재 등록 목록과 소비처 상태는 [`APPROVED_REFERENCE_MANIFEST.json`](APPROVED_REFERENCE_MANIFEST.json)을 따른다.
